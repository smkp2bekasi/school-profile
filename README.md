# SMKS Patriot 2 School Profile Website

A modern, responsive school profile website built with Bootstrap 5 and jQuery.

## Project Structure

```
school-profile/
├── public/
│   └── index.html          # Main HTML file
├── src/
│   ├── assets/
│   │   └── images/         # All images and logos
│   ├── css/
│   │   └── style.css       # Custom styles
│   └── js/
│       └── script.js       # Custom JavaScript
├── docs/                   # Documentation files
├── package.json            # Project dependencies
└── README.md              # This file
```

## Features

- Responsive design with Bootstrap 5
- Smooth scrolling navigation
- Modern CSS animations
- Mobile-friendly layout
- Professional school branding

## Setup Instructions

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start development server:

   ```bash
   npm start
   ```

3. Open your browser to `http://localhost:8080`

## Dependencies

- Bootstrap 5.3.3
- jQuery 3.7.1
- Popper.js 1.16.1

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
